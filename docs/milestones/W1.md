# W1 — Scaffold and data contract

Status: in progress (checkpoint 3: accessible shell, Home, About).

W1 establishes the technical foundation. It is not Film browse, search,
SEO beyond basic document structure, TMDB attribution, or deployment.

---

## Scope

- Sibling Astro repository (`cultural-archive-web`)
- Current stable Astro, TypeScript, static output, no adapter
- No React/Vue/Svelte, no Tailwind
- Plain CSS and design tokens (checkpoint 3)
- Public JSON snapshot in `src/data/` (checkpoint 2)
- Types, `schema_version` fail-fast, Film catalog module (checkpoint 2)
- Sync script with public/private guardrails (checkpoint 2)
- Accessible global shell, Home stub, About stub (checkpoint 3)
- Vitest foundation
- Zero unnecessary client JavaScript

## Not in W1

Film poster grid, movie detail, `/movies/`, taxonomy routes, search,
filters, stats page, JSON-LD/sitemap, final TMDB attribution, image
pipeline, webfonts, analytics, deploy config, other collections, CMS,
API, SSR, authentication.

---

## Navigation

W1: Home, About. Film is added in W2 when `/movies/` exists.

---

## Learning

Generated implementation must not replace understanding. Pause after:

1. Scaffold and documentation boundary (this checkpoint)
2. Public JSON, types, validation, catalog access
3. Accessible shell, tokens, Home, About (this checkpoint)

Keyboard pass of the shell: pending owner verification after this
checkpoint. Landmarks, skip link, Home/About `aria-current`, and
visible `:focus-visible` are implemented in the layout.

Concepts for this checkpoint: semantic landmarks; accessibility tree;
skip links; `aria-current`; `:focus-visible`; CSS custom properties;
global vs scoped CSS; why Home needs no hydration; using public stats
without building Film browse.

---

## Done when

- Separate static Astro repo exists with TypeScript and no UI framework
- Public snapshot is committed and validated (`schema_version === 1`)
- Sync copies only the three public files and refuses private inputs
- Semantic shell + Home/About render from public stats
- Home extra client JS is 0
- Contract and sync tests exist
- Keyboard pass of the shell is recorded
- Learning pauses happened

## Accessibility gate (checkpoint 3)

Landmarks, skip link, `lang`, heading structure, focus-visible,
keyboard navigation, contrast-safe tokens, reduced-motion baseline,
logical source order.

## Performance gate (checkpoint 3)

No hydration, no UI-framework runtime, CSS budget started, no webfonts,
no layout-shifting media. Do not invent image LCP/CLS claims in W1.
