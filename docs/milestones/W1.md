# W1 — Scaffold and data contract

Status: complete.

W1 established the static Astro foundation: public JSON validation and
sync, a semantic accessible shell, Home and About only, no client
JavaScript, pnpm as the package manager. Tests, `pnpm check`, and
`pnpm build` passed.

W1 is not Film browse, search, SEO beyond basic document structure,
TMDB attribution, or deployment.

---

## Scope

- Sibling Astro repository (`cultural-archive-web`)
- Current stable Astro, TypeScript, static output, no adapter
- pnpm (`packageManager` `pnpm@10.33.0`)
- No React/Vue/Svelte, no Tailwind
- Plain CSS and design tokens
- Public JSON snapshot in `src/data/`
- Types, `schema_version` fail-fast, Film catalog module
- Sync script with public/private guardrails
- Accessible global shell, Home, About
- Vitest foundation
- Zero unnecessary client JavaScript

## Not in W1

Film poster grid, movie detail, `/movies/`, taxonomy routes, search,
filters, stats page, JSON-LD/sitemap, final TMDB attribution, image
pipeline, webfonts, analytics, deploy config, other collections, CMS,
API, SSR, authentication.

---

## Navigation

W1: Home, About. Film is added in a later wave when `/movies/` exists.

---

## Learning

Generated implementation must not replace understanding. Pauses were:

1. Scaffold and documentation boundary
2. Public JSON, types, validation, catalog access
3. Accessible shell, tokens, Home, About

Concepts: semantic landmarks; accessibility tree; skip links;
`aria-current`; `:focus-visible`; CSS custom properties; global vs
scoped CSS; why Home needs no hydration; using public stats without
building Film browse.

---

## Done when

- Separate static Astro repo exists with TypeScript and no UI framework
- Public snapshot is committed and validated (`schema_version === 1`)
- Sync copies only the three public files and refuses private inputs
- Semantic shell + Home/About render from public stats
- Home extra client JS is 0
- Contract and sync tests exist
- Learning pauses happened
- `pnpm test`, `pnpm check`, and `pnpm build` pass

---

## Accessibility gate

Landmarks, skip link, `lang`, heading structure, focus-visible,
keyboard navigation, contrast-safe tokens, reduced-motion baseline,
logical source order.

## Performance gate

No hydration, no UI-framework runtime, CSS budget started, no webfonts,
no layout-shifting media. Do not invent image LCP/CLS claims in W1.
