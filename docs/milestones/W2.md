# W2 — Film collection experience

Status: complete (uncommitted until review).

W2 established Film as the first real collection experience: static
browse and detail routes, poster-forward accessible cards, a restrained
Film record, and in-page alphabetic navigation. It does not implement
taxonomy, credits, selection-state, Dispatches, or a newspaper homepage.

---

## Goal

Present one collection well. A visitor can enter Film from primary
navigation, browse every published catalog film, and open a stable
permalink for any of them.

Current membership is the `schema_version` 1 catalog snapshot. That is
not explicit `selected_for_archive` selection.

---

## Checkpoints

1. Information architecture: `/movies/`, `/movies/[slug]/`, Film nav,
   text-first index, publisher slugs, browse order helpers.
2. Poster-forward browse: `FilmCard`, native TMDB `<img>` `srcset`,
   reserved 2:3 geometry, lazy loading, missing-poster fallback, wide
   collection layout.
3. Film detail hierarchy: identity, descriptive metadata, TMDB audience
   rating as external reception, Sources. Copy/availability/codecs,
   backdrop, and tagline remain hidden.
4. Alphabetic in-page navigation, article-aware English browse keys,
   static contextual return links, Home/About integration, W2 gates and
   documentation.

---

## Current routes

```text
/                Home (contract-proof snapshot + Film CTA)
/about/          About
/movies/         Film browse
/movies/[slug]/  Film detail
```

Navigation: Home · Film · About. No dead collection links.

---

## Presentation rules

- Browse sort/group key ignores a leading English A / An / The.
  Display titles never change. Non-English articles are not stripped.
- Numeric and other non A–Z browse titles use a `#` section.
- Alphabet index lists only populated sections.
- One pair of section-end links, not per card: “Back to Film index”
  (`#film-index`) and “Back to top” (`#top`).
- Detail pages return to the Film card via a slug-derived fragment
  (`/movies/#film-solaris-1972-593`, label “Back to Solaris in Film”).
  Breadcrumb remains `Film > Title` and points at `/movies/`. Detail
  pages also include “Back to top”.
- Narrow browse uses a comfortable centered single column, then the
  intrinsic multi-column grid. Narrow detail stacks and centers the
  poster and short identity; long overview text stays start-aligned.
- Sticky/fixed header and hamburger/disclosure menus are deferred.
- Poster `alt=""` when visible title/year (browse) or `h1` (detail)
  already name the work.
- No `role="list"` on the Film grids.

## Accessibility decisions

- WCAG 2.1 AA baseline, 2.2 AA design target
- Native HTML first; ARIA only when needed
- Film index is a second `nav` named “Film index”
- Letter headings (`h2`) for ~26 groups, not 772 card headings
- Keyboard fragment links; no JS scroll helpers
- Modest `scroll-margin-top` on Film index, letter headings, and cards
- Sparse records omit empty sections rather than printing N/A

---

## Zero JavaScript

W2 pages are static HTML/CSS. Posters are remote TMDB files with
`loading="lazy"` on browse. Detail posters may load eagerly. There is
no hydration, filter runtime, infinite scroll, or client router.

## Learning

Film is a collection-specific presentation of a public snapshot.
Alphabetic anchors keep one crawlable document usable. Explicit
relationships (later: more by a director) are preferred over opaque
recommendations. Music, Books, and Art should reuse accessibility and
static-publication practice, not Film’s poster grid or metadata shape.
